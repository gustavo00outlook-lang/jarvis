# JARVIS do Gustavo

Esta pasta é a porta de entrada. O programa inteiro está na raiz do repositório.

https://github.com/gustavo00outlook-lang/jarvis

No computador de quem recebeu:

1. Instale Node.js, Python 3.13 e o Ollama.
2. Baixe o modelo: `ollama pull hermes3`
3. Dê dois cliques em `INICIAR-JARVIS.bat` na raiz do projeto.
4. Abra http://127.0.0.1:3000

A primeira voz demora, porque o modelo baixa sozinho.

Não há senha nem chave de API aqui. Esta cópia sobe no PC de quem abrir. Ela não entra no JARVIS que já está ligado no computador do Gustavo.
